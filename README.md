A. Deskripsi Proyek
MabarStation adalah platform website interaktif yang dirancang sebagai pusat komunitas gamer untuk mencari teman “Main Bareng” (mabar).

B. Cara Menjalankan
Untuk menjalankan proyek ini secara lokal, ikuti langkah-langkah berikut:

  1. Clone repository:
   `git clone https://github.com/a0wannabee/praktikum-git-25-555725-SV-25839.git`
  2. Buka folder proyek menggunakan *code editor* (misalnya Visual Studio Code).
  3. Jalankan file `index.html` di browser.

| No | Perintah | Penjelasan |
|----|----------|------------|
| 1 | `git clone <url>` | Menggandakan repositori dari GitHub ke komputer lokal |
| 2 | `git status` | Mengecek status working directory dan staging area |
| 3 | `git add .` | Menambahkan semua perubahan ke staging area |
| 4 | `git commit -m "pesan"` | Menyimpan perubahan ke riwayat lokal |
| 5 | `git log --oneline --graph` | Menampilkan riwayat commit dalam bentuk grafik |
| 6 | `git checkout -b <nama>` | Membuat dan pindah ke branch baru |
| 7 | `git branch` | Melihat daftar branch |
| 8 | `git push origin <branch>` | Mengirim commit ke GitHub |
| 9 | `git pull origin main` | Mengambil update terbaru dari repository |
| 10 | `git rebase -i HEAD~3` | Interactive rebase untuk squash commit |
